# Kevin Lin — Portfolio

Personal portfolio site hosted at [asura369.github.io](https://asura369.github.io).

## Stack

- **HTML** — Semantic, accessible markup
- **CSS** — Custom design system with CSS custom properties
- **JavaScript** — Vanilla JS for scroll animations, nav tracking, and mobile menu

## Local Development

Open `index.html` in a browser, or use a local server:

```bash
npx -y serve .
```

## Deployment

Push to the `main` branch — GitHub Pages will serve `index.html` automatically. No build step required.

## Updating Content

Edit the relevant `<section>` in `index.html` directly. Styles are in `index.css`, interactions in `index.js`.
